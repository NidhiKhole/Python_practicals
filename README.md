# Python Practice Scripts Collection

A collection of beginner-friendly Python scripts demonstrating core programming concepts, data structures, and algorithms.

## 📂 Included Scripts

### 1. Student Result System (`Practical1.py`)
* **Concepts Used:** Functions, Positional Arguments, Keyword Arguments, Default Arguments, and Variable-Length Arguments (`*args`).
* **Description:** Takes student marks as input, calculates the total and percentage, assigns a grade using default parameters, and displays the details using various argument passing techniques.

### 2. Linear Search using Strings (`Practical2.py`)
* **Concepts Used:** Lists, `for` loops, Conditional Statements, and String Matching.
* **Description:** Searches for a specific name within a predefined list of strings and outputs its position if found, or a "not found" message otherwise.

### 3. Lambda Functions & List Comprehensions (`Practical3.py`)
* **Concepts Used:** Lambda Functions, List Comprehensions, and Basic Data Filtering.
* **Description:** Demonstrates concise data manipulation by generating a list of squares using a lambda function and filtering even numbers using list comprehension.
